# FreshCart Pipelines

Data Engineering Assignment: From Git to Gold.

## Project Overview

This project demonstrates four major components:

1. Git and CI/CD
2. FreshCart ELT Pipeline using Snowflake
3. Iris Classification using Mage AI
4. Food Order Event Streaming using RabbitMQ

## Technologies Used

- Python 3.12
- Git and GitHub
- Snowflake
- Mage AI
- Scikit-learn
- Pytest
- RabbitMQ

## Project Structure

- elt/: FreshCart ELT pipeline
- iris_project/: Iris ML pipeline
- stream/: Event streaming scripts
- tests/: Automated tests
- .github/workflows/: CI configuration
